# 🎓 Smart-Lecture-Assistant

An AI-powered lecture assistant built with **Streamlit** and the **Google Gemini API**. It processes lecture materials, slide photos, whiteboard snapshots, and audio notes to generate structured executive summaries, core conceptual breakdowns, and interactive revision quizzes.

---

## ✨ Features

- **Executive Summary:** Concise overviews of the core lecture topic.
- **Key Concepts & Definitions:** Highlights important formulas, terms, and theories.
- **Timestamped / Detailed Notes:** Well-formatted study notes with clear topic headings.
- **Interactive Revision Quiz:** Multiple-choice practice questions with answers to test understanding.
- **Export & Download:** Save your generated notes directly as Markdown files.

---

## 🛠️ Tech Stack

- **Frontend / App Framework:** Streamlit
- **AI Model:** Google Gemini API (`gemini-2.5-flash`)
- **Language:** Python 3.10+
